# Universe ChatGPT Voice Assistant

- Этот проект — универсальное ядро ассистента с API. Matrix и другие приложения подключаются через адаптеры; протоколы конкретного мессенджера не должны попадать в ядро.
- Предпочтения пользователя: Node.js, TypeScript 7.1, esbuild. На 2026-11-11 ветка 7.1 доступна как `7.1.0-beta`; не заменять её другой веткой без явного объяснения.
- Исходный вариант доступа к моделям — аккаунт и подписка ChatGPT. Не переключать проект на платный Voice API и не создавать расходы без соответствующей задачи пользователя.
- Все материалы разработки сохранять в этом каталоге. Секреты, токены, SSH-пароли и содержимое личных чатов не записывать в исходники, документы, вывод диагностики или Git.
- Начинать с одного владельца, одной голосовой сессии и одного демонстрационного инструмента. Дополнительные провайдеры и системы расширений добавлять по реальной потребности.
- Команды выполняются на машине исполнителя. Доступ к рабочему компьютеру пользователя требует исполнителя или настроенного подключения к этой машине.
- По запросу пользователя backend использует штатные shell/file инструменты Codex и наследует sandbox CLI. `approvalPolicy: never` задан явно для headless-прототипа; не утверждать, что approval-режим CLI тоже наследуется. Отказ о доступе допустим только после реальной попытки выполнить подходящий инструмент.
- Matrix VM уже обслуживает работающие сервисы. Проверка доступа не означает разрешение на их замену, остановку или изменение сети.
- Отделять наличие методов в протоколе Codex от успешного сквозного голосового теста. Подписочный WebRTC v3, Matrix E2EE и полная связка с локальным node --version проверены через smoke:command; холодное позднее подключение нового криптоустройства остаётся ограничением.
